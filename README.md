# دليل هاكاثون الابتكار — تطبيق ويب للجوال

موقع تفاعلي مُحسّن للهواتف (iPhone و Android) يُفتح عبر رمز QR، ويعرض:

1. **الأجندة التفصيلية** — جدول غامر ومتحرك للفعاليات على مدار اليومين.
2. **المخطط ثلاثي الأبعاد** — نموذج تفاعلي للطابقين، يمكن للمستخدم تدويره
   وتكبيره والنقر على أي قاعة لعرض تفاصيلها وما تقدّمه.

الواجهة بالكامل باللغة العربية (RTL)، بتصميم داكن فاخر مستوحى من هوية
مركز الابتكار — الهيئة السعودية للحكومة الرقمية.

---

## Interactive event guide (mobile web app)

A phone-first web app (iPhone/Android), opened via a QR code, with an immersive
Arabic agenda and an interactive **3D floor plan** (rotate / pinch-zoom / tap a
room for details). Built with Vite + Three.js, fonts and 3D bundled locally so
it works on venue Wi‑Fi with no external dependencies.

## التشغيل محليًا · Run locally

```bash
npm install
npm run dev        # خادم التطوير
npm run build      # بناء الإنتاج إلى dist/
npm run preview    # معاينة نسخة الإنتاج
```

## ✏️ تعديل المحتوى · Editing content

كل النصوص (الأجندة + الغرف) في ملف واحد فقط:

```
src/data.js
```

- **الأجندة:** المصفوفة `AGENDA` — كل عنصر يحوي الوقت والعنوان والوصف والغرفة
  المرتبطة. غيّر الأوقات/العناوين هنا.
- **الغرف:** المصفوفة `ROOMS` — الاسم، الوصف، وما تقدّمه، مع إحداثيات الغرفة
  في المخطط (`plan`).
- **بيانات الفعالية:** الكائن `EVENT` (العنوان، التاريخ، المكان، جهة التنظيم).

> ⚠️ **ملاحظة:** أوقات وعناوين الأجندة الحالية **مبدئية للعرض التوضيحي**
> (مبنية على تسلسل هاكاثون واقعي). استبدلها بالجدول الرسمي عند توفّره — يكفي
> تعديل `src/data.js`. أوصاف الغرف مستمدّة من الدليل التعريفي لمركز الابتكار
> ومن مخطط الموقع.

## النشر عبر QR · Deploy for the QR code

يوجد سير عمل جاهز في `.github/workflows/deploy.yml` ينشر الموقع تلقائيًا على
**GitHub Pages** عند كل دفع.

خطوات التفعيل لمرة واحدة:

1. في مستودع GitHub: **Settings → Pages → Build and deployment → Source = GitHub Actions**.
2. ادفع إلى الفرع (سيبدأ النشر تلقائيًا).
3. الرابط سيكون بالشكل: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.

> يستخدم البناء مسارات نسبية (`base: './'`)، لذا يعمل الموقع على أي مسار
> استضافة دون تعديل.

### رمز QR

بعد النشر، افتح الموقع على الجوال ← الصفحة الرئيسية ← زر **«عرض رمز QR للمشاركة»**.
تُولَّد الشيفرة تلقائيًا لعنوان الموقع الحالي، ويمكن عرضها على شاشة أو طباعتها
لمشاركتها مع الحضور.

## البنية · Structure

```
index.html          # نقطة الدخول (RTL, عربي)
src/
  main.js           # هيكل التطبيق والتنقّل بين الشاشات
  data.js           # ← كل المحتوى القابل للتعديل (أجندة + غرف)
  agenda.js         # شاشة الأجندة الغامرة
  floor3d.js        # المخطط ثلاثي الأبعاد (Three.js)
  qr.js             # مولّد رمز QR
  icons.js          # أيقونات SVG
  style.css         # نظام التصميم
.github/workflows/deploy.yml   # نشر GitHub Pages
```

## ملاحظات تقنية · Technical notes

- **أداء:** يُحمّل محرّك Three.js فقط عند فتح شاشة المخطط (تحميل كسول)، فتبقى
  الصفحة الرئيسية والأجندة سريعة جدًا على شبكات الفعاليات.
- **دون اتصال خارجي:** الخطوط العربية (Tajawal/Cairo) ومحرّك ثلاثي الأبعاد
  ومولّد QR كلها مضمّنة محليًا — لا اعتماد على أي CDN.
- **اللمس:** سحب بإصبع = تدوير، إصبعان = تكبير/تحريك، نقرة = اختيار قاعة.
